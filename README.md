# Studio Digi Mix — 3D Photography Studio Website

A cinematic, interactive 3D website built for **Studio Digi Mix** (Maligaon, Guwahati, Assam). Features interactive Three.js light-field particle animations, background camera exploded-view video, editorial typography, services showcase, portfolio galleries, and inquiry contact form.

## 🚀 Features

- **Interactive 3D Light-Field**: Three.js WebGL particle field and orbital geometry responding to user view.
- **Cinematic Video Hero**: High-definition camera exploded-view animation (clean, watermark-free).
- **Modern Design**: Editorial styling with Cormorant Garamond and Space Grotesk typography.
- **Responsive Layout**: Mobile-first fluid experience across mobile, tablet, and desktop viewports.
- **Booking & Contact**: Studio location details, WhatsApp/call integration, and project inquiry form.

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite 7
- **3D / Graphics**: Three.js
- **Styling**: Tailwind CSS 4 + custom design tokens
- **Icons**: Lucide React
- **UI Components**: Radix UI primitives + Sonner toasts

## 📦 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- [pnpm](https://pnpm.io/) (or npm / yarn)

### Installation

```bash
# Clone the repository
git clone https://github.com/ANIKETCHAND/studio.git
cd studio

# Install dependencies
pnpm install
```

### Running Locally

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Building for Production

```bash
pnpm build
```

The production assets will be built in the `dist/` directory.
